# 클로드 코드에 붙이는 AI 에이전트 툴 4개

전부 무료 오픈소스이고 클로드 코드에 연결해서 쓴다. 사용자는 비개발자(쇼핑몰 운영 등)일 수 있으니
한국어로, 한 번에 한 단계씩, 명령은 복사해서 넣을 수 있게 안내한다.

## 1. 무엇을 쓸지 고르기

| 툴 | 한 줄 | 이럴 때 | 라이선스 | 저장소 |
| --- | --- | --- | --- | --- |
| Trail-code (구 Graft) | 폴더 지도 + 작업 노하우 저장 | 클로드가 파일 찾느라 헤맬 때 | MIT | `trailhq/Trail-Code` |
| Agency Agents | 19개 부서, AI 직원 약 300명 | 분야별 전문가에게 맡기고 싶을 때 | MIT | `msitarzewski/agency-agents` |
| Codebase Memory MCP | 프로젝트 관계도를 그래프로 기억 | 하나 고치면 다른 데가 망가질 때 | MIT | `DeusData/codebase-memory-mcp` |
| OpenMontage | 주제 → 완성 영상 | 영상 제작을 통째로 맡길 때 | AGPL-3.0 | `calesthio/OpenMontage` |

추천 시작 순서:
- 코딩 프로젝트가 있으면 **Trail-code 또는 Codebase Memory 중 하나만**. 둘 다 '지도' 역할이라 겹친다.
- 콘텐츠가 목적이면 **Agency Agents → OpenMontage** 순서.

## 2. 공통 준비물

| 확인할 것 | 명령 | 필요한 툴 |
| --- | --- | --- |
| Node.js | `node -v` (18 이상) | 전부 |
| Git | `git --version` | 전부 |
| Python 3.10+ | `python3 --version` | OpenMontage |
| FFmpeg | `ffmpeg -version` | OpenMontage |

없는 게 있으면 사용자 허락을 받고 설치한다.
설치 방법은 둘 중 편한 걸로: ① 아래 명령을 터미널에 붙여넣기 ② 클로드 코드에 "[깃허브 주소] 이거 설치해줘"라고 말하기.
권한 확인 창이 뜨면 내용을 확인한 뒤 허용하라고 알려 준다.
**설치가 끝나면 클로드 코드를 재시작해야** 새 도구(MCP·에이전트)를 인식한다. 꼭 안내한다.

이 툴들은 내 컴퓨터에서 도는 도구다. 핸드폰 앱이 아니라 데스크톱 앱 코드 탭이나 터미널 Claude Code에서 진행한다.

## 3. Trail-code (구 Graft) — 폴더를 지도 한 장으로

이름이 바뀌었어도 예전 `graft` 명령은 그대로 작동한다.

```
npm install -g @trailhq/trail-code
trail init
```

`trail init`이 하는 일: 어떤 AI에 연결할지 묻기 → 폴더 지도 만들기 → 노하우 폴더(`.trail`) 만들기 → 클로드 코드에 연결(MCP·상태표시줄·훅).
- 클로드 코드만 연결: `trail init --agents claude`
- 바뀌는 내용만 미리 보기: `trail init --dry-run`

쓰는 법:
- 구조 파악: "이 프로젝트 지도 보고, 주문 엑셀을 정리하는 코드가 어디 있는지랑 어떤 파일들이랑 연결돼 있는지 설명해줘."
- 노하우 저장(같은 실수 반복 방지): `trail note "상품 사진은 항상 1080×1350으로 저장, 파일명은 상품코드_컬러"`

참고 수치(개발팀 자체 측정이라 내 프로젝트에선 다를 수 있음):
- 통제 테스트 162회: 응답 시간 60%↓, 비용 32%↓, 도구 호출 46%↓, 정확도 동일
- SWE-bench 50문제: 해결 27개 → 33개, 토큰 23%↓, 시간 32%↓

지도와 노하우는 내 컴퓨터에만 저장되고 API 키가 필요 없다.

## 4. Agency Agents — AI 직원 약 300명

19개 부서, 약 300명(2026년 10월 기준 298명). 직원은 전부 `.md` 설명 파일이다.

```
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
./scripts/install.sh --tool claude-code
```

- **필요한 부서만** 까는 걸 기본으로 권한다. 300명을 다 깔면 고르기 어렵다:
  `./scripts/install.sh --tool claude-code --division marketing,design`
- 쇼핑몰이면 처음엔 마케팅·디자인·유료 광고·고객지원 4개 부서를 추천한다.
- 실행이 안 되면(권한 거부): `chmod +x scripts/install.sh` 후 다시 실행.
- 터미널이 싫으면 같은 저장소의 데스크톱 앱으로도 설치할 수 있다.

부서 예시: 엔지니어링·디자인·마케팅·유료 광고·세일즈·제품·프로젝트 관리·테스트·보안·고객지원·재무·전략·리서치 등.

쓰는 법(직원 이름을 불러서 시킨다):
- 한 명: "마케팅 부서 콘텐츠 담당 에이전트로 이번 주 인스타 릴스 기획 3개 짜줘. 타겟은 20대 후반 여성, 신상 니트 출시 주간이야."
- 여러 명 한 팀: "에이전트 오케스트레이터로 진행해줘. 디자인 담당이 가을 기획전 페이지 구성 잡고, 광고 담당이 메타 광고 카피 3종 쓰고, 마지막에 검수 담당이 둘 다 점검해서 고칠 점 알려줘."

직원 `.md` 파일을 열어 우리 가게에 맞게 고치거나, 새 직원을 직접 만들 수도 있다.

## 5. Codebase Memory MCP — 구조를 통째로 기억

파일 간 관계를 그래프로 저장한다(158개 언어). 클로드 코드를 자동으로 찾아 연결한다.

```
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash
```

- 관계도 화면(UI)까지 보려면 끝을 `| bash -s -- --ui`로 바꿔 설치.
- 인터넷에서 받은 스크립트를 바로 실행하는 방식이다. 실행 전에 사용자에게 그렇다는 걸 알리고 동의를 받는다.
- 설치 후 클로드 코드를 **프로젝트 폴더에서** 열고, 첫 프롬프트로 색인을 시킨다.

쓰는 법:
- 처음 한 번(색인): "코드베이스 메모리로 이 프로젝트 색인해줘. 끝나면 전체 구조를 한 장으로 요약해줘."
- 고치기 전에 영향 범위: "주문 저장하는 함수를 고치려고 해. 이걸 바꾸면 어디가 영향을 받는지 먼저 다 찾아서 보여주고, 그 범위 안에서만 수정해줘."
- 흐름 추적: "고객이 결제 버튼 누르고 나서 주문 완료 메일이 가기까지 어떤 함수들을 거치는지 순서대로 추적해줘."

실수를 줄여 주는 도구지 0으로 만드는 도구는 아니다. 수정 후엔 바뀐 부분을 꼭 확인하라고 안내한다.

## 6. OpenMontage — 클로드 코드를 영상 제작팀으로

조사 → 대본 → 이미지·영상 → 편집 → 렌더링까지 한 번에.

```
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup
```

준비물: Python 3.10+ · FFmpeg · Node.js 18+. 설치 후 **이 폴더에서** 클로드 코드를 열고 만들 영상을 말한다.

쓰는 법:
- 설명 영상: "'니트 오래 입는 세탁법' 45초 세로 설명 영상 만들어줘. 애니메이션 스타일, 한국어 내레이션과 자막, 마지막에 '프로필 링크에서 신상 보기'. 시작 전에 예상 비용부터 보여줘."
- 실사 몽타주: "'가을 도시 산책' 30초 감성 몽타주 만들어줘. 무료 실사 영상만 사용, 내레이션 없이 잔잔한 음악."

만들 수 있는 종류: 애니메이션 설명·다큐 몽타주·시네마틱·아바타 진행자·토킹헤드·화면 시연·팟캐스트 쇼츠·숏폼 클립·다국어 더빙 등.

비용:
| 구분 | 내용 |
| --- | --- |
| 0원 | API 키 없이 가능 — 무료 내레이션(Piper), 무료 공개 영상·사진 |
| 선택 | 이미지·영상 생성 키를 넣으면 1편에 대략 0.15~3달러(개발자 안내) |
| 안전장치 | 실행 전 비용 견적, 기본 총예산 상한 10달러, 0.5달러 넘는 작업은 승인 요청 |

프롬프트에 항상 "시작 전에 예상 비용부터 보여줘"를 넣으라고 권한다.

**라이선스 주의(AGPL-3.0)**: 만든 영상을 쓰는 건 괜찮지만, 이 코드를 고쳐서 서비스로 남에게 제공하면 소스 공개 의무가 생길 수 있다.

## 7. 4개를 한 팀으로

Trail-code·Codebase Memory는 기억, Agency Agents는 전문 인력, OpenMontage는 제작 라인을 맡는다.

1. **지도 깔기** — 작업 폴더에 Trail-code(또는 Codebase Memory)로 지도를 만든다.
2. **전문가 배치** — Agency Agents 마케팅·디자인 부서 설치. 기획은 마케팅 직원, 페이지는 디자인 직원.
3. **영상 라인** — 마케팅 직원이 짠 기획을 OpenMontage에 넘겨 숏폼으로.
4. **노하우 쌓기** — 잘 된 방식은 `trail note`로 저장. 다음 작업부터 반영된다.

한 번에 시키는 프롬프트:

```
이번 주 신상 니트 출시 준비하자. 순서대로 진행하고 단계마다 결과 보여줘.
1. 마케팅 부서 콘텐츠 담당 에이전트가 릴스 기획 3개를 짜.
2. 그중 1번 기획으로 OpenMontage에서 30초 세로 영상을 만들어. 시작 전에 비용 견적부터.
3. 디자인 담당 에이전트가 기획전 페이지 문구 구성을 잡아.
4. 오늘 잘 된 방식은 trail note로 저장해.
```

## 8. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 설치했는데 도구·에이전트가 안 보임 | 클로드 코드 재시작 |
| `trail`/`graft` 명령을 못 찾음 | `npm install -g @trailhq/trail-code` 재실행, 새 터미널 열기 |
| `install.sh` 권한 거부 | `chmod +x scripts/install.sh` |
| 에이전트가 너무 많아 고르기 어려움 | `--division`으로 필요한 부서만 다시 설치 |
| Codebase Memory가 구조를 모름 | 프로젝트 폴더에서 열었는지 확인 후 색인 프롬프트 다시 |
| OpenMontage `make setup` 실패 | `python3 --version`(3.10+), `ffmpeg -version` 확인 후 재시도 |
| 영상 비용이 걱정됨 | API 키 없이 0원 모드로, 프롬프트에 "비용 견적부터" |

명령이나 옵션이 위와 다르게 동작하면 각 저장소 README가 최신이다. README를 확인해서 따른다.
