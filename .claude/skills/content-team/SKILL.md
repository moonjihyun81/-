# 컨텐츠팀 클힉지 (클로드 + 힉스필드 1인 콘텐츠 팀)

출처: 최고수준 「클로드 하나로 굴리는 1인 콘텐츠 팀」 노션 가이드를 정리한 스킬.
사용자는 비개발자일 수 있다. 한국어로 짧게, 한 단계씩, 복사해 쓸 수 있는 프롬프트로 안내한다.

핵심: **AI마다 잘하는 일만 맡긴다.** 힉스필드 하나만 연결하면 그 안의 오픈AI GPT 이미지 모델까지 같이 쓸 수 있어서, 챗GPT를 따로 연결할 필요가 없다.

## 팀 역할표

| 순서 | 담당 | 하는 일 |
| --- | --- | --- |
| 1 | 🧠 클로드 | 터진 릴스 분석 → 기획 → 대본 |
| 2 | 🎨 GPT (힉스필드 안) | AI 아바타 이미지 |
| 3 | 🎬 힉스필드 | 아바타로 영상 만들기 |
| 4 | ✂️ 클로드 코드 | 자막·컷 편집 (Remotion) |
| 5 | 📊 힉스필드 + 클로드 | 바이럴 예측 평가 → 다시 고치기 |

## 공통 규칙 (항상 지킨다)

- **크레딧이 드는 작업(영상 분석·이미지·영상·바이럴 예측)은 실행 전에 예상 크레딧을 먼저 알리고 허락을 받는다.** 클로드에서 만드는 이미지·영상은 힉스필드 무제한·무료 생성이 적용되지 않고 매번 차감된다. 처음엔 짧은 길이로 테스트하자고 권한다.
- 확인 안 되는 내용은 지어내지 않고 **"추정"** 이라고 표시한다.
- 인스타 링크만으로는 영상을 볼 수 없다. 링크만 받으면 지어내지 말고, 화면 녹화 파일을 작업 폴더에 넣어 달라고 하거나 `reels-reader` 스킬(다운로드+받아쓰기+장면 캡처)을 쓴다.
- 타인의 릴스는 **분석용으로만**. 녹화본을 다시 올리지 않는다. 가져오는 건 흐름이고, 대사·화면은 새로 만든다.
- 커넥터 메뉴 이름·힉스필드 기능은 업데이트로 바뀔 수 있다. 안 맞으면 현재 도구 목록을 확인한다.

## 이 환경에서 쓰는 힉스필드 도구 (mcp__Higgsfield__*)

| 단계 | 도구 |
| --- | --- |
| 연결·잔액 확인 | `balance` |
| 영상 업로드 | `media_upload` → `media_confirm` (못 읽으면 `media_upload_widget`) |
| 릴스 장면 분석 | `video_analysis_create` → `video_analysis_status` |
| 아바타 이미지 | `generate_image` (GPT Image 모델, 9:16, quality high, 2k) |
| 아바타 영상 | `generate_video` (말하는 아바타는 최대 30초) |
| 결과 대기·확인 | `jobs_wait`, `show_generation_by_ids` |
| 바이럴 평가 | `virality_predictor` |

도구 이름이 다르면 ToolSearch로 `higgsfield`를 검색해 찾는다.

## 0단계. 팀원 연결 (딱 한 번)

1. claude.ai 또는 클로드 데스크톱 → 설정 → 커넥터 (화면에 따라 사용자 지정 → 커넥터)
2. 커스텀 커넥터 추가 → 이름 `Higgsfield`, 주소 `https://mcp.higgsfield.ai/mcp`
3. 연결 → 힉스필드 계정으로 로그인
4. 확인: "내 힉스필드 크레딧 잔액 알려줘" → 숫자가 나오면 성공

준비물: 클로드 데스크톱 앱(Pro 이상, 작업은 Code 탭), 힉스필드 계정 + 크레딧.

## 1단계. 클로드 — 터진 릴스 분석하고 대본 쓰기

### ① 한 편씩 뜯어보기

```
작업 폴더에 넣은 릴스 영상을 힉스필드 영상 분석으로 장면별로 분석해줘.
그리고 아래 다섯 가지로 정리해줘.

1. 대본: 나온 말과 자막을 시간 순서대로
2. 첫 3초: 뭘 보여주고 무슨 말을 했는지, 왜 여기서 스크롤이 멈췄을지
3. 전개: 장면마다 무슨 역할인지 한 줄씩
4. 화면: 자막 크기·색, 움직임, 장면 전환 특징
5. 마무리: 마지막에 뭘 하라고 했고, 보는 사람은 뭘 얻는지

확인 안 되는 부분은 지어내지 말고 "추정"이라고 표시해줘.
마지막에 이 영상에서 가져올 점 3가지만 한 줄씩 적어줘.
크레딧이 드는 기능이면 실행 전에 먼저 알려줘.
```

영상 분석이 잘 안 되면: 장면 바뀔 때마다 캡처 5~8장 + 캡션 복사본을 올리고, 첫 줄만 "올린 캡처와 캡션을 보고"로 바꾼다.

### ② 여러 개 모아서 공식 찾기 (①을 여러 편 돌린 같은 대화에서)

```
지금까지 분석한 릴스를 전부 비교해줘.

1. 3개 이상에서 반복되는 첫 3초·전개·화면·마무리 패턴을 표로
2. 반응이 특히 좋았던 영상에만 있는 특징
3. 너무 많이 써서 이제 뻔해 보이는 것
4. 한 줄 정리: "잘 되는 영상은 ○○로 시작해서 ○○로 끝난다"
```

🎯 잘 된 영상만 넣으면 "다 좋다"로 끝난다. 반응이 덜 나온 영상도 섞어야 차이가 보인다.

### ③ 내 대본 쓰기

```
위에서 찾은 패턴을 그대로 써서 내 릴스 대본 1개를 써줘.

[내 정보]
- 내 분야:
- 보는 사람:
- 이번에 말하고 싶은 것:

[대본에 넣을 것]
1. 첫 3초 화면 + 한마디
2. 장면 순서 (5장면 이내)
3. 장면별 대사
4. 마지막 댓글 유도 문구
5. 장면마다 필요한 아바타 모습 설명
```

## 2단계. GPT — AI 아바타 만들기 (힉스필드 안의 GPT Image)

```
힉스필드에서 GPT Image 모델로 대본에 맞는 AI 아바타 이미지를 한 장 만들어줘.
세로 9:16, 정면, 상반신, 자연광, 실제 사진 느낌으로. 품질은 high, 해상도는 2k로.
인물 설명: [나이대·성별·헤어·옷 스타일]
만들기 전에 크레딧이 얼마 드는지 먼저 알려줘.
```

- **품질·해상도는 꼭 지정한다.** 힉스필드 기본값은 품질 low, 해상도 1k라 화질이 떨어져 보인다.
- 마음에 들 때까지 인물 설명만 바꿔 다시 요청.
- **아바타는 한 장을 정해서 계속 쓴다.** 같은 문장이어도 얼굴이 바뀔 수 있으니, 이후엔 "처음 만든 아바타 이미지를 참고 이미지로 넣어서 만들어줘". (의상만 바꿀 땐 `outfit-swap` 스킬 참고)

## 3단계. 힉스필드 — 아바타로 영상 만들기

```
방금 만든 아바타 이미지로 힉스필드에서 세로 9:16 영상을 만들어줘.
대본 1번 장면처럼 [동작·표정·배경]으로, 길이는 n초
만들기 전에 크레딧이 얼마 드는지 먼저 알려줘.
```

- 장면마다 한 번씩 요청한다. 다 되면: "만든 영상들 전부 작업 폴더에 장면 순서대로 내려받아줘."
- 자동으로 안 받아지면 higgsfield.ai 내 생성 목록에서 직접 받아 `1.mp4`, `2.mp4`… 순서대로 이름을 바꿔 둔다.
- 말하는 아바타 영상은 한 번에 **최대 30초**. 긴 릴스는 장면별로 나눠 만들고 4단계에서 이어 붙인다.

## 4단계. 클로드 코드 — 말로 편집하기 (Remotion)

### 처음 한 번: 편집 도구 설치

```
영상 편집에 쓸 Remotion 프로젝트를 my-video 폴더에 만들고, Remotion 스킬까지 설치해줘.
명령어는 npx create-video --yes --blank my-video 랑 npx remotion skills add 를 써줘.
```

"Node.js가 없다"고 나오면 Node.js부터 설치하고 이어서 진행한다.

### 편집 시키기

```
작업 폴더의 영상들을 장면 순서대로 이어서 세로 릴스 한 편으로 편집해줘.

- 대본 대사를 자막으로 넣기 (화면 가운데 아래, 크고 굵게)
- 첫 3초는 자막을 더 크게
- 장면 사이 끊기는 부분은 짧게 자르기
- 마지막에 댓글 유도 문구 넣기

다 되면 mp4로 내보내줘.
```

수정은 말로 한 번에 하나씩: "2번째 장면 자막 색 노란색으로 바꿔줘", "전체 길이 15초 안으로 줄여줘".
마음에 드는 스타일이 나오면 "이 스타일 그대로 기억해서 다음 영상도 똑같이 해줘" → 스타일을 파일(예: `my-video/STYLE.md`)로 남겨 다음에 재사용한다.

## 5단계. 평가 — 터질 때까지 고치기

### 바이럴 점수 받기

```
편집한 영상을 힉스필드 바이럴 예측으로 분석해줘.
첫 3초 훅 강도랑 사람들이 빠져나갈 것 같은 구간을 알려줘.
크레딧이 들면 실행 전에 먼저 알려줘.
```

### 고치고 다시 평가

```
방금 평가에서 약하다고 나온 부분만 고쳐서 다시 편집해줘.
그리고 다시 바이럴 예측 돌려서 전이랑 비교해줘.
```

만족할 때까지 이 두 개만 반복한다. 🎯 점수는 참고용 — 업로드 후 실제 조회수가 나온 내 릴스를 1단계 ① 프롬프트로 다시 분석해 다음 기획에 반영한다.

## 잘 안 될 때

| 이럴 때 | 이렇게 |
| --- | --- |
| 클로드가 힉스필드를 못 찾음 | Code 탭에 `/mcp` 입력 → Higgsfield가 목록에 있는지 확인. 없으면 claude.ai 설정 → 커넥터에서 연결 상태 확인 |
| 분석 내용이 이상함 | "확인 안 되는 부분은 추정이라고 표시하고 다시 정리해줘" |
| 아바타 얼굴이 매번 달라짐 | 처음 만든 아바타 이미지를 계속 참고 이미지로 쓰기 |
| 편집이 마음에 안 듦 | 한 번에 하나씩만 고쳐 달라고 하기 |
| 화질이 낮음 | 이미지 요청에 품질 high, 해상도 2k 명시 |
