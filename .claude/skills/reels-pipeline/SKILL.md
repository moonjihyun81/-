# 릴스 파이프라인 (포착 → 검수 → 제작 → 올림)

사용자는 1인 사장이고 비개발자다. 한국어로 짧게 보고하고, 결정할 것만 묻는다.

## 1. 보드
- 더기븐 보드(폰에서 열림): https://claude.ai/artifact/J9aPWpNGMgY6R1PD8BuJDU
  - 카드는 보드의 저장소 `cards` 컬렉션에 있다. Claude는 ArtifactData로 읽고 쓴다.
  - 카드 필드: stage(capture·review·make·done·drop), region(국내·해외·패션), title, acct, url,
    views(그 릴스 조회수), avg(계정 평소 조회수), why(왜 터졌나 한 줄), ours(우리 버전 한 줄),
    verse(말씀 주소), format, result(올린 뒤 3일 결과), log{capture,review,make,done: YYYY-MM-DD}.
  - ours·verse·format 세 칸이 차야 제작(make)으로 보낼 수 있다.
- 다른 브랜드에 쓸 때는 보드를 복제하고 형식·말씀 칸 이름만 바꾼다.

## 2. 포착 기준
- **평소 대비 3배 이상**이면 포착, 5배 이상은 우선 검수.
- 평소 = 그 계정 릴스 탭 최근 약 30~40개 조회수의 **중간값**(평균 아님. 한두 개 대박이 평균을 끌어올림).
- 최근 6개월 안, 고정된 앞 3개 제외, 팔로워 1천~50만 계정.

## 3. 찾는 방법
1. **사용자 PC 크롬으로 반자동 스캔(무료, 추천)**: Claude in Chrome으로 `instagram.com/<계정>/reels/`를 열고,
   4번쯤 스크롤한 뒤 화면에 보이는 릴스 카드 글자(예: "3.3만")를 읽어 중간값과 배수를 계산한다.
   화면에 보이는 것만 읽는다. 인스타 내부 API를 직접 부르지 않는다(막혀 있고 약관 위험).
   하루 계정 5~10개 정도로 천천히. 3배 이상인 릴스만 열어 캡션(og:title)과 화면을 보고 카드로 넣는다.
2. **손으로 넣기(폰)**: 릴스에서 공유 → 링크 복사 → 보드 `+ 포착하기`에 붙여넣고 조회수와 평소 조회수를 적는다.
3. 계정 찾기: `#말씀` `#오늘의말씀` 인기 게시물에서 작성자 계정을 따라간다. 해외는 #bibleverse #christianapparel.
4. 유료 자동 수집(필요해지면만): Firecrawl/ScrapeCreators `instagram/user-reels`(호출당 크레딧),
   Apify Instagram Reel Scraper(무료 월 크레딧 소량). 인스타 공식 API는 남의 계정 조회수를 주지 않는다.

## 4. 검수 체크 (카드 빈칸 채우기)
1. 말씀 한 구절로 바꿀 수 있나 (개역한글 + KJV/WEB 병기, 원문 대조).
2. 우리 도구로 만들 수 있나: 실사 얼굴 연기 X / 올리브 마스코트, 무료 실사 소재, 맨투맨 실물, PC Codex 이미지 O.
3. 누구에게 보낼 이유가 있나 (공유가 가장 센 신호).
4. 구조만 빌린다: 훅 방식, 길이, 댓글 키워드→DM 같은 틀. 화면·문장·음악은 새로 만든다.
   남의 방송·영상 클립을 잘라 올리는 형식은 하지 않는다.
- 영상 내용을 자세히 봐야 하면 `reels-reader` 스킬로 장면별 정리를 먼저 한다.

## 5. 하루 목표와 흐름
- 포착 5 → 검수 3 → 대본 확정 1. 올리기는 콘텐츠 캘린더(월·수·목 20:30)에 맞춘다.
- 대본 확정되면: 기획·컷·프롬프트 작성 → PC Codex(ChatGPT 로그인) 또는 사용자 ChatGPT로 생성 → 스레드 검토 → 업로드.
- 올리고 3일 뒤 result 칸에 조회·공유·저장을 적는다. 매주 일요일, 우리한테 잘 맞은 구조를 한 줄로 정리한다.

## 6. 하지 않는 것
- 조회수 약속. 3배 기준은 고르는 기준일 뿐이다.
- 레퍼런스 베끼기, 남의 영상 재업로드(인스타 원본성 규칙으로 노출도 깎인다).
- "인기 숏폼을 그대로 복제" 하는 튜토리얼식 방법은 구조만 참고한다.
- 결제·가입·구독 대신하기.
