# Open Generative AI 같이 쓰기

영상·이미지 AI마다 따로 결제하지 않고, 앱 하나에서 여러 모델(Flux, Midjourney, Kling, Veo, Seedance, Wan 등)을 고르는 무료 오픈소스 스튜디오다(MIT 라이선스).
클라우드 모델은 muapi.ai를 거쳐 실행되고, 데스크톱 앱에서는 내 컴퓨터로 돌리는 로컬 실행도 된다.
사용자는 비개발자일 수 있으니 한국어로, 한 번에 한 단계씩, 명령은 복사해서 넣을 수 있게 안내한다.

## 0. 원칙

- 설치본은 **공식 저장소 릴리스 페이지**(https://github.com/Anil-matcha/Open-Generative-AI/releases)나 공식 사이트에서만 받는다.
- 계정 비밀번호와 API 키 값은 화면에 출력하거나 파일·프롬프트·저장소에 저장하지 않는다. 키는 `muapi auth configure`의 입력창에만 넣게 한다.
- 기존 파일과 설정은 지우지 않는다.
- 순서를 지킨다: 경고 해제 → 탭 구조 → 첫 생성 → 시네마 → 자동화. 화면에서 한 번도 안 만들어 본 상태로 자동화부터 하면 결과가 이상해도 원인을 못 찾는다.
- 앱 자체에는 콘텐츠 필터가 약하다. 실존 인물 얼굴 합성, 남의 저작물 도용, 오해를 부르는 가짜 영상은 만들지 않도록 안내한다.

## 1. 상황 확인

| 확인할 것 | 방법 | 안 되면 |
| --- | --- | --- |
| 이미 설치됐는지 | 응용 프로그램 목록·시작 메뉴에 "Open Generative AI" | 2단계로 |
| 설치 없이 써도 되는지 | 브라우저로 https://muapi.ai/open-generative-ai | 같은 스튜디오가 웹에서 열림(로컬 실행만 빠짐) |
| 자동화까지 할지 | `node --version`, `npm --version` | `command not found: npm` → https://nodejs.org 에서 LTS 설치 후 터미널 재시작 |

## 2. 설치 (약 5분)

릴리스 페이지 맨 위 최신 버전에서 고른다.

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| 맥 (M1·M2·M3·M4) | 이름에 `arm64`가 붙은 `.dmg` |
| 맥 (인텔) | `arm64`가 없는 `.dmg` |
| 윈도우 | `Setup`이 붙은 `.exe` |
| 우분투·리눅스 | `.deb`(권장) 또는 `.AppImage` |

맥 종류를 모르면: 사과 메뉴 → "이 Mac에 관하여" → 칩 이름에 M이 있으면 `arm64`.

**첫 실행 경고 해제** (서명 없는 설치본이라 뜨는 안내, 바이러스 아님 — 파일을 지우지 말 것)

- 맥: 시스템 설정 → 개인 정보 보호 및 보안 → 아래쪽 차단 안내에서 "확인 없이 열기". 또는 터미널에서
  ```
  xattr -cr "/Applications/Open Generative AI.app"
  ```
  아무 메시지 없이 다음 줄로 넘어가면 성공.
- 윈도우: 파란 경고창에서 "추가 정보" → "실행".
- 리눅스: AppImage가 안 열리면 `.deb`를 쓰거나 `sudo apt install libfuse2`. 우분투 24.04 이상은 `.deb`가 샌드박스 설정까지 해 준다.

앱이 열리면 로그인하거나 muapi.ai 키를 넣는다. 그래야 클라우드 모델 목록이 열린다.

## 3. 탭 구조 (탭 = 모델 묶음)

| 탭 | 하는 일 |
| --- | --- |
| Image Studio | 글로 이미지 만들기, 가진 이미지 고치기 |
| Video Studio | 글로 영상 만들기, 이미지 한 장 움직이기 |
| Cinema Studio | 카메라·렌즈·초점 거리·조리개를 정해 영화 같은 장면 |
| Lip Sync Studio | 얼굴 사진·영상에 목소리 붙이기 |

참고 이미지를 올리면 모델 목록이 "고치기·움직이기" 모델로 자동으로 바뀐다. 원하는 모델이 안 보이는 문제의 절반은 탭이나 업로드 여부가 다른 것이다.

## 4. 첫 이미지와 첫 영상

1. Image Studio → 모델 아무거나 → 아래 문장 → 생성
   ```
   늦은 오후 창가에 앉아 노트북을 보는 사람, 따뜻한 햇빛, 사진처럼 사실적으로
   ```
   잠시 뒤 이미지가 뜨고 아래 기록 영역에 남는다. 내려받기 버튼으로 원본 저장.
2. Video Studio → 방금 이미지를 시작 장면으로 올림 → 아래 문장 → 생성
   ```
   카메라가 아주 천천히 뒤로 물러나며 창밖 풍경까지 보여준다
   ```
   첫 생성은 대기열 때문에 오래 걸릴 수 있다.

프롬프트는 짧게보다 "눈에 보이듯" 적는 편이 결과가 좋다.

## 5. 시네마 스튜디오

"영화처럼"이라고 쓰는 대신 카메라 값을 숫자로 정한다. 고른 값은 프롬프트에 촬영 용어로 자동으로 붙는다.

| 원하는 화면 | 초점 거리 | 조리개 |
| --- | --- | --- |
| 인물 한 명, 감성적으로(배경 흐림) | 35mm | f/1.4 |
| 제품·풍경, 앞뒤 모두 또렷하게 | 24mm | f/11 |
| 무난하게 | 아무거나 | f/4 |

초점 거리는 8mm(넓게)~85mm(대상만 크게). 값을 정했으면 장면 설명은 짧아도 된다. 예: `빗속 골목을 걸어가는 사람의 뒷모습, 젖은 바닥에 비친 간판 불빛`. 값만 바꿔 두세 번 돌려 차이를 보여 준다.

## 6. 클로드 코드 자동화 (약 10분)

같은 작업을 여러 번 반복할 때만 권한다. 터미널에서 한 줄씩:

```
npm install -g muapi-cli
muapi auth configure
npx skills add SamurAIGPT/Generative-Media-Skills --all -a claude-code
```

- 1줄: 명령 실행 도구 설치 / 2줄: 키 저장(키는 https://muapi.ai/dashboard 에서 발급, 이름이 아닌 키 값을 넣는다) / 3줄: 생성 미디어 스킬을 클로드 코드에 붙임.
- 확인: `muapi image models` → 모델 이름이 줄줄이 나오면 성공. 아무것도 안 나오면 키 저장부터 다시.
- 첫 생성 테스트: `muapi image generate "a sunset over mountains" --model flux-schnell --download ./outputs`

그다음 클로드 코드에 꺾쇠만 바꿔 넣게 한다.

```
설치된 생성 미디어 스킬을 사용해 아래 작업을 진행해 주세요.
목표: <만들 것 한 줄 — 예: 신제품 소개용 이미지 5장과 15초 영상 1개>
분위기: <원하는 느낌 — 예: 따뜻한 오후 햇빛, 미니멀한 배경>
진행 방식:
- 먼저 어떤 모델을 쓸지와 예상 단계를 짧게 보여 주세요.
- 이미지를 먼저 만들고, 가장 나은 한 장을 골라 영상으로 움직이세요.
- 결과 파일은 <저장 폴더 — 예: ./outputs>에 내려받아 주세요.
- 마지막에 만든 파일 목록과 실패한 단계를 알려 주세요.
```

지정한 폴더에 파일이 실제로 저장돼야 완료다. 파일이 없으면 완료로 보고하지 않는다.
MCP로 쓰고 싶으면 `muapi mcp serve`를 MCP 서버로 등록한다(키는 환경 변수 `MUAPI_API_KEY`로).

## 7. 무료 범위

- 앱: MIT 오픈소스, 무료.
- 클라우드 모델: muapi.ai를 거쳐 실행. 무거운 모델을 많이 돌리면 크레딧이 든다. 생성 전에 사용자에게 비용이 들 수 있다고 한 번 알린다.
- 완전 무료: **데스크톱 앱의 로컬 실행**(키 불필요, 웹 버전에는 없음).
  - 이미지: 설정 → Local Models → sd.cpp 엔진 설치(클릭 한 번) → 모델 하나 내려받기 → Image Studio에서 "⚡ Local" 켜고 생성.
  - 영상: 그래픽카드(NVIDIA/AMD) 있는 컴퓨터에 Wan2GP(https://github.com/deepbeepmeep/Wan2GP)를 직접 설치한 뒤 설정 → Local Models → Wan2GP에서 폴더 지정 → Check. 맥은 Wan2GP를 못 돌리므로 다른 GPU 컴퓨터의 MCP 서버로 연결해야 한다.
  - 메모리 8GB 맥은 가장 가벼운 모델(SD 1.5)부터. 큰 모델은 멈출 수 있다.

## 8. 자주 막히는 곳

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 맥에서 앱이 안 열림 | 서명 없는 설치본 차단 | "확인 없이 열기" 또는 `xattr -cr` 한 번 |
| 윈도우 파란 경고창 | 코드 서명 없음 | 추가 정보 → 실행 |
| 리눅스 AppImage 실행 실패 | 시스템 구성 요소 부족 | `.deb` 사용 또는 `sudo apt install libfuse2` |
| 원하는 모델이 목록에 없음 | 탭·입력 방식이 다름 | 생성인지 편집인지 확인, 참고 이미지 업로드 여부 바꾸기 |
| 생성 버튼 반응 없음 | 로그인·키 미설정 | 다시 로그인하거나 키 재입력 |
| `command not found: npm` | Node.js 없음 | nodejs.org LTS 설치 후 터미널 재시작 |
| `muapi image models`가 빈 결과 | 키 저장 안 됨 | `muapi auth configure` 다시 |
| 로컬 모델이 너무 느림 | 메모리 부족으로 CPU 실행 | 더 가벼운 모델 또는 클라우드 모델 |

## 9. 마무리 보고

실행한 명령, 앱 버전과 Node.js·npm 버전, 설치·로그인 상태, 생성한 결과물 경로, 남은 오류와 다음 조치를 짧게 정리한다. 하나라도 실패했으면 완료라고 하지 말고 원인과 다음 조치를 적는다.
