# 아바타

목표: **사진 한 장이 아니라 캐릭터 시트 한 장**으로 아바타를 고정하고, 같은 얼굴로 영상을 10개, 20개 계속 뽑는다.
사진 한 장만 넣으면 춤추다가 얼굴이 바뀌고, 팔이 늘어나고, 다른 사람이 된다. 이걸 잡는 게 이 스킬이다.

사용자는 비개발자일 수 있으니 한국어로, 한 단계씩, 프롬프트는 복사해서 쓸 수 있게 준다.

## 0. 전체 순서

| 단계 | 할 일 | 도구 |
| --- | --- | --- |
| 1 | 캐릭터 시트 1장 만들기 | ChatGPT |
| 2 | 비디오 → Genjutsu → **모션 트랜스퍼** 열기 | 힉스필드 |
| 3 | 모션 라이브러리에서 영상 고르기 (또는 내 영상 업로드) | 힉스필드 |
| 4 | 캐릭터 시트 넣고, 프롬프트 비우고 생성 | 힉스필드 |
| 5 | 시트는 그대로, 영상만 바꿔서 반복 | 힉스필드 |

필요한 것: ChatGPT, 힉스필드 계정(크레딧 필요).

이 세션에 Higgsfield MCP 도구가 연결돼 있으면 사용자가 직접 클릭하는 대신 도구로 같은 순서를 밟을 수 있다(8번 참고). 연결이 없으면 화면 클릭 순서를 안내한다. Claude가 직접 이미지를 못 만드는 환경이면 "제가 만들 수는 없고, ChatGPT에 넣을 지시문을 드릴게요"라고 분명히 말한다.

## 1. 캐릭터 시트 — 한 장에 꼭 들어갈 3가지

캐릭터 시트 = 애니메이션·게임에서 캐릭터를 고정할 때 쓰는 기준표. 한 장 안에 아래 3컷이 다 있어야 한다.

| 컷 | 역할 | 없으면 |
| --- | --- | --- |
| ① 정면 얼굴 클로즈업 (필수) | 얼굴 기준점. 눈·코·입·턱선 | 얼굴이 흐릿하게 나온다 |
| ② 정면 전신 (**가장 중요**) | 동작을 입히는 몸. 팔·다리가 겹치면 안 된다 | 몸이 늘어나거나 잘린다 |
| ③ 좌우 45도 얼굴 (권장) | 고개 돌릴 때 얼굴 유지 | 옆을 볼 때 다른 사람이 된다 |

**왜 3장이 아니라 한 장인가:** AI가 "이 세 개가 같은 사람"이라는 걸 한 장 안에서 바로 보기 때문에 얼굴이 훨씬 덜 흔들린다.

### <프롬프트 1> 캐릭터 시트 만들기 (ChatGPT)

```
[첨부한 사진의 인물 / 아래 설명의 인물]로 AI 아바타용 캐릭터 시트를 한 장으로 만들어 주세요.
한 장 안에 다음 3컷을 나란히 배치합니다.
① 정면 얼굴 클로즈업 (크게, 눈·코·입·턱선이 선명하게)
② 정면 전신 (머리부터 발끝까지, 팔은 몸에서 살짝 떨어뜨리고 다리는 붙지 않게, 팔·다리가 서로 겹치지 않는 차렷 자세)
③ 왼쪽 45도 얼굴, 오른쪽 45도 얼굴
세 컷 모두 완전히 같은 사람, 같은 헤어·피부톤·의상·조명·화풍으로 그려 주세요.
배경은 단색 밝은 회색, 글자나 로고는 넣지 마세요.
인물 설명: [나이대, 성별, 헤어, 의상, 화풍(실사/반실사/애니)]
```

### 체크 (넘어가기 전에 반드시)

- 세 컷이 **같은 사람**으로 보이는가?
- 전신 컷에서 **팔·다리가 겹치지 않는가?** 손이 몸에 붙어 있거나 다리가 꼬여 있으면 다시 뽑는다.
- 얼굴 클로즈업이 **충분히 큰가?**

어긋나면 이렇게 고친다:

```
45도 얼굴을 정면 얼굴이랑 똑같은 사람으로 다시 만들어줘. 나머지는 그대로 유지해줘.
```
```
얼굴 클로즈업을 더 크게 해서 시트를 다시 만들어줘. 얼굴·의상·화풍은 그대로.
```

> ⚠️ **시트는 꼭 저장한다.** 이 한 장이 아바타의 '원본'이다. 잃어버리면 같은 얼굴을 다시 못 만든다. 파일명 예: `avatar_sheet_v01.png`

## 2. 힉스필드에서 모션 트랜스퍼 열기

1. higgsfield.ai 로그인
2. 위 메뉴 **비디오** → 탭에서 **Genjutsu**
3. 왼쪽에서 **모션 트랜스퍼** 선택 (**오브젝트 스왑 아님** — 자주 헷갈린다)

모션 트랜스퍼 = 영상의 움직임만 빼서 내 사진에 입히는 것. 영상 속 사람은 사라지고 내 아바타가 그 동작을 한다.

## 3. 영상 고르기 — 모션 라이브러리

왼쪽 위 **모션 라이브러리**를 누르면 영상 목록이 나온다.

| 탭 | 내용 |
| --- | --- |
| Higgsfield | 공식 영상 |
| 커뮤니티 인기 ⭐ | 사람들이 제일 많이 쓴 영상. **처음엔 여기서 고른다** |
| 커뮤니티 최신 | 방금 올라온 것 |

**내가 찍은 영상도 된다.** 모션 라이브러리 대신 왼쪽 위 칸에 직접 업로드. 폰 세워놓고 10초 춤추면 그게 내 아바타 영상이 된다. (다른 사람이 찍은 영상을 쓸 땐 사용 권한을 확인하게 한다.)

## 4. 시트 넣고 생성

1. 영상 아래 **"캐릭터, 제품 또는 의상 추가하기"** 클릭
2. 업로드 → 미디어 업로드 → **캐릭터 시트** 올리기
3. **프롬프트는 비워둔다** (영상 그대로 따라 하게)
4. **생성하기**

→ 영상 속 사람이 내 아바타로 바뀌어서 똑같이 움직인다. 다운받아서 올리면 끝.

### 얼굴이 흔들리면

- 시트에서 얼굴 클로즈업이 작게 나왔는지 확인 → ChatGPT에 "얼굴 클로즈업을 더 크게" 해서 다시 뽑는다.
- 사진 칸은 최대 30장까지 들어가니, **시트 + 얼굴 클로즈업 단독 한 장**을 같이 올려도 된다.

### 장면(배경)을 바꾸고 싶으면

프롬프트를 켜고 이렇게 적는다.

```
@image1의 캐릭터가 옥상에서 춤추는 모습
```
```
같은 동작, 새로운 장소: 밤의 도쿄
```

## 5. 같은 아바타로 계속 뽑기 (여기가 핵심)

세팅을 한 번 하면 **시트는 그대로, 영상만 바꾼다.**

```
캐릭터 시트 그대로 두고
→ 모션 라이브러리에서 다른 영상 선택
→ 생성하기
```

영상 하나에 약 3분. 하루 5개 뽑으면 일주일치 릴스가 나온다.

### 옷만 바꾸고 싶으면

ChatGPT에 시트를 첨부하고:

```
같은 인물, 옷만 [검정 원피스]로 바꿔서 캐릭터 시트를 다시 만들어줘. 얼굴·헤어·체형·화풍·구도는 그대로 유지해줘.
```

얼굴은 유지되고 옷만 바뀐다. 새 시트도 따로 저장한다(`avatar_sheet_black-dress_v01.png`). 옷 교체를 더 꼼꼼히 하려면 `outfit-swap` 스킬의 검수 방법을 함께 쓴다.

## 6. 문제 해결 요약

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 춤추다 얼굴이 바뀐다 | 사진 1장만 넣음 / 얼굴 컷이 작음 | 캐릭터 시트 사용, 얼굴 클로즈업 크게, 얼굴 단독 컷 추가 업로드 |
| 고개 돌리면 다른 사람 | 45도 얼굴 없음 | 시트에 좌우 45도 얼굴 추가 |
| 팔·다리가 늘어나거나 잘림 | 전신 컷에서 팔다리가 겹침 / 전신이 잘림 | 팔다리가 떨어진 정면 전신으로 시트 재생성 |
| 아바타가 아니라 물건이 바뀜 | 오브젝트 스왑을 선택함 | **모션 트랜스퍼**로 다시 |
| 동작을 이상하게 따라 함 | 프롬프트에 이것저것 적음 | 프롬프트 비우고 다시 생성 |
| 다음 영상에서 얼굴이 달라짐 | 매번 새 사진/새 시트를 씀 | 저장해둔 **같은 시트 원본**만 계속 사용 |

## 7. 지킬 것

- **실존 인물(연예인·지인 등)의 얼굴로 아바타를 만들지 않는다.** 본인 얼굴이거나 새로 만든 가상 인물로 한다. 본인 사진을 쓰는 경우에도 결과물을 어디에 올릴지 본인이 결정하게 한다.
- 크레딧이 드는 작업이니 생성 전에 사용자가 비용을 알고 진행하게 한다.
- 결과물의 상업적 이용·초상권·음원 저작권은 실제로 쓰는 서비스의 최신 약관을 확인하게 한다. 인스타에 올릴 땐 플랫폼의 AI 생성 콘텐츠 표시 규칙을 따른다.

## 8. Higgsfield MCP 도구가 연결돼 있을 때

연결된 Higgsfield 서버의 지시를 먼저 따른다(서버가 안내하는 워크플로가 이 문서보다 우선). 대략의 흐름:

1. 캐릭터 시트가 없으면: 사용자가 **명시적으로 시트를 원할 때만** 서버의 `character-sheet` 워크플로 안내(`get_workflow_instructions`)를 받아 만든다. 이미 있으면 업로드(`media_upload` → 업로드 → `media_confirm`)해서 media id를 받는다.
2. 모션 영상 고르기: Genjutsu 프리셋 목록(`get_presets`, source/category `genjutsu`, 인기는 `genjutsu-trending`)을 보여주고 사용자가 고르게 한다. **목록을 보여준 것만으로 생성하지 않는다.**
3. 생성: `generate_video`로 모션 트랜스퍼(`hf_mult_motion_control`)를 실행한다. 크레딧 견적을 먼저 알리고 사용자 동의 후 진행.
4. 결과 확인 후, 같은 시트 media id를 재사용해 영상만 바꿔 반복한다.

도구 이름·인자는 서버 버전에 따라 바뀔 수 있으니 실제 스키마를 확인하고 쓴다.
