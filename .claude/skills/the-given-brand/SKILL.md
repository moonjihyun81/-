# 더기븐 (THE GIVEN) 브랜드 가이드

믿음을 일상에서 자연스럽게 입는 크리스천 의류 브랜드다.
결과물은 한국어로 설명하고, 새로 만드는 모든 것은 이 문서의 규칙을 먼저 확인한 뒤 만든다.
가이드가 바뀌면 **가장 최근 날짜의 가이드가 우선**한다(현재 기준: 2026-11-13).

## 1. 브랜드 기본

| 항목 | 내용 |
| --- | --- |
| 브랜드명 | THE GIVEN (더기븐) |
| 콘셉트 | Faith · Art · Everyday |
| 슬로건 | **Wear what you believe.** |
| 인스타그램 | @thegiven.official |
| 스타일 | 모던 미니멀 + 감각적인 스트릿 |
| 판매 방식 | 사전 주문(프리오더) 후 제작 |

예전 자료의 `thegiven.wear`, "Already Given, Always Grace"는 이전 안이다. 사용자가 다시 쓰자고 하지 않으면 새 결과물에는 쓰지 않는다.

## 2. 색

| 구분 | 색 | 참고값 |
| --- | --- | --- |
| 메인 | 크림 | `#F1E7D7` |
| 메인 | 차콜 | `#302B25` |
| 보조 | 올리브 | 포인트 색(마크, 작은 강조) |
| 보조 | 베이지 · 토프 | 배경, 단색 티 컬러웨이 |

- 한 화면에 메인 1개 + 보조 1개 정도만 쓴다. 원색·형광·금박은 쓰지 않는다.
- 배경은 탄트지(종이 질감)처럼 은은한 질감의 크림·차콜 면을 기본으로 한다.

## 3. 마크 (확정 2026-11-13)

- **심플한 십자가**. 아래 기둥을 중간에서 끊어 작은 공백을 두고, 끊어진 아래 조각은 **짧게**(점처럼) 둔다.
- 티셔츠에는 **왼쪽 가슴에 작게 자수**로만 넣는다. 크림 원단 = 올리브 실, 차콜 원단 = 크림 실, 그 밖에 브라운 실도 가능.
- 마크 모양을 바꾸거나 장식(빛, 가시관, 비둘기 등)을 덧붙이지 않는다.
- 원본 파일: 프로젝트 `lookbook/emblem_cross_v3_*.png`, PC `문서\ChatGPT\나의앞으로계획\더기븐\마크_CI\`.

## 4. 글과 말투

- 성경 말씀은 **영문 중심**으로, 짧게 쓴다. 출처 표기(예: Hebrews 12:1)는 작게.
- 과한 종교 장식, 설교조 문장, 느낌표 남발은 피한다. 담백하고 따뜻하게.
- 피드 디자인에서 한글 문장을 넣을 때는 **한글은 크게 가운데**, 영문은 작게 보조로 둔다.
- 캡션 예시 구조: 한 줄 메시지 → 제품 한 줄 → 프리오더 안내 → 해시태그 3~5개.

## 5. 제품 라인

티셔츠 10종이 목표다.

| 라인 | 수량 | 성격 |
| --- | --- | --- |
| Sacred | 4 | 말씀·신앙 메시지가 중심인 티 |
| Daily | 3 | 매일 입는 미니멀 티(마크 중심) |
| Running · FAITH IN MOTION | 3 | 러닝·운동용 티, 크림 래글런 등 |

첫 출시 3종: **THE GIVEN**(오병이어, 다섯 개의 떡과 두 마리 물고기), **RUN THE RACE**, **BE STILL**.
기본 핏은 가먼트다잉 오버핏, 컬러는 크림 · 워싱 차콜 · 올리브.

## 6. AI 모델과 화보

남녀 커플 모델을 **항상 같은 사람으로 고정**한다.

| 모델 | 특징 |
| --- | --- |
| 남 (GIVEN M) | 20대 후반 한국인, 자연스러운 검은 웨이브 헤어, 차분하고 세련된 분위기 |
| 여 (GIVEN W) | 20대 후반 한국인, 자연스러운 다크브라운 헤어, 내추럴 메이크업, 부드럽고 자신감 있는 표정 |

촬영 규칙:
- 베이지·그레이 배경 또는 따뜻한 콘크리트 벽, 자연광, 미니멀 패션 화보.
- 인스타 피드 비율 **4:5**.
- 기본 컷: 커플 티 화보, 야외 러닝(여성 크림 래글런), 자수 클로즈업, 접은 티 플랫레이.
- 옷에는 왼쪽 가슴 마크 하나만. 다른 글자·로고는 넣지 않는다.
- AI로 만든 연출 이미지임을 캡션에 표기한다.
- 생성할 때마다 기준 얼굴 사진(`AI모델\00_기준얼굴\`)을 함께 넣고, 결과는 `AI모델\` 폴더에 저장한 뒤 `모델카드.md` 생성 기록 표에 한 줄 추가한다.

기본 프롬프트(영문, 복사해서 사용):

```
Use the people in the reference images as the models: keep the same faces, hairstyles and overall mood. Man: natural black wavy hair, calm refined look. Woman: natural dark brown hair, natural makeup, soft confident expression. Oversized cream / washed charcoal tees, each with one tiny embroidered cross on the left chest (lower stem cut with a small gap, short dot below). Beige-grey background, natural light, minimal fashion editorial, 4:5, film grain. No other text or logos.
```

## 7. 목표

- 티셔츠 10종 디자인 완성
- 인스타 피드 50개 (4:5, 같은 커플 모델로 일관되게)

## 8. 지켜야 할 규칙

- 레퍼런스(예: rhythmsofgrace.ph 등)는 **분위기만** 참고한다. 디자인·그래픽·문구는 더기븐이 직접 만든 것만 쓴다. 남의 디자인을 베끼거나 살짝 바꿔 쓰지 않는다.
- 결제, 구독, 요금제 업그레이드는 **대신 하지 않는다**. 크레딧이 없으면 멈추고 사용자에게 알린다.
- 실존 인물의 얼굴을 합성하지 않는다.
- 확정된 사항(마크, 색, 제품명 등)은 사업계획서(`문서\ChatGPT\나의앞으로계획\THE GIVEN 사업계획서.html`)에도 반영한다.

## 9. 결과물 점검표

만든 것을 넘기기 전에 확인한다.

- [ ] 슬로건·인스타 계정이 최신 가이드와 같은가
- [ ] 색이 크림·차콜 + 보조 1색 안에 있는가
- [ ] 마크가 확정 형태(끊긴 아래 기둥, 짧은 조각)이고 왼쪽 가슴에 작게 있는가
- [ ] 말씀은 영문 중심, 과한 종교 장식이 없는가
- [ ] 화보 모델이 고정 커플과 같은 얼굴이고 비율이 4:5인가
- [ ] 레퍼런스를 베낀 부분이 없는가
