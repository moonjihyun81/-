# 캐릭터 의상만 바꾸기 (GPT 편집 + Claude 검수)

목표는 하나다. **같은 사람(캐릭터)으로 보이게 유지하면서 옷만 바꾼다.**
사용자는 비개발자일 수 있으니 한국어로, 한 단계씩, 프롬프트는 복사해서 쓸 수 있게 준다.

## 0. 역할 나누기

| 도구 | 맡는 일 | 주의 |
| --- | --- | --- |
| ChatGPT 이미지 생성·편집 | 마스터 캐릭터 만들기, 업로드한 이미지에서 옷 부분 바꾸기, 결과 재편집 | 옷 말고 얼굴·배경까지 바뀔 수 있어 매번 검수 필요 |
| Claude | 캐릭터 설정표, 편집 프롬프트 작성, 원본과 결과 비교 검수, 재수정 지시문 | 환경에 따라 직접 이미지를 만들거나 편집하지 못한다. 그럴 땐 "제가 만들 수는 없고, ChatGPT에 넣을 지시문을 드릴게요"라고 분명히 말한다 |

이 세션에 이미지 생성 도구(예: Higgsfield, Canva, Figma 이미지 생성)가 연결돼 있으면 ChatGPT 대신 그 도구로 같은 순서를 밟아도 된다. 원칙은 같다.

## 1. 준비: 마스터 이미지와 고정 규칙

- 마스터 이미지 3종이 이상적이다: ① 얼굴 클로즈업 ② 정면 전신 ③ 3/4 각도 전신. 머리·피부톤·체형·조명·화풍이 같아야 한다.
- 처음엔 **정면 전신 1장**만으로 시작해도 된다.
- 고정 규칙을 글로 적어 둔다: 눈·코·입 형태, 얼굴형, 헤어 길이와 가르마, 키·체형 비율, 피부톤, 그림체, 카메라 거리.
- 바꿔도 되는 것은 **의상과 액세서리뿐**이라고 못 박는다.

## 2. 작업 순서 (ChatGPT)

1. 새 대화에 마스터 이미지 업로드 → 아래 <프롬프트 1>로 특징부터 정리시킨다.
2. 같은 대화에서 <프롬프트 2>로 의상만 바꾼다. 편집 화면의 **선택 영역 기능으로 옷 부분만 칠해서** 지정하면 훨씬 안정적이다.
3. 결과를 원본과 나란히 놓고 본다. 얼굴이나 머리가 달라졌으면 **결과물을 계속 고치지 말고, 원본 마스터를 다시 올려 처음부터** 편집한다. 결과물 위에 덧편집하면 변화가 누적된다.
4. 의상별 최종본을 따로 저장한다. 예: `character_master.png`, `outfit_suit_v01.png`, `outfit_casual_v01.png`

### <프롬프트 1> 캐릭터 분석

```
첨부한 이미지를 이 캐릭터의 마스터 원본으로 사용합니다. 얼굴형, 눈·코·입, 헤어스타일, 피부톤, 체형, 반실사 2D 그림체를 구체적으로 분석하여 '고정 요소'와 '변경 가능 요소'로 나누어 캐릭터 설정표를 작성해 주세요. 이미지에 보이지 않는 특성은 추정하지 마세요.
```

### <프롬프트 2> 의상 교체

```
첨부한 마스터 이미지 속 동일한 캐릭터를 편집해 주세요. 의상만 [검정 재킷, 흰 셔츠, 검정 슬랙스]로 교체합니다. 얼굴, 눈·코·입, 머리카락, 피부톤, 체형, 포즈, 카메라 구도, 배경, 조명, 반실사 2D 화풍은 유지해 주세요. 옷 이외 영역은 가능한 한 원본 그대로 보존하세요. 변경이 필요한 의상 경계만 자연스럽게 연결해 주세요. 텍스트나 로고는 추가하지 마세요.
```

`[ ]` 안만 바꿔 쓴다. 실사 모델이면 "반실사 2D 화풍"을 "사진 질감과 색감"으로 바꾼다.

## 3. 검수 (Claude)

마스터(A)와 결과(B)를 함께 받으면 <프롬프트 3> 기준으로 직접 비교한다. 사용자가 다른 Claude 창에서 쓰고 싶어 하면 프롬프트를 그대로 준다.

### <프롬프트 3> 일관성 검수

```
이미지 A는 마스터 캐릭터, 이미지 B는 의상 교체 결과입니다. 얼굴형, 눈·코·입, 헤어스타일, 피부톤, 체형, 포즈, 카메라 구도, 그림체, 배경을 항목별로 비교해 주세요. 각 항목을 유지/경미한 변화/큰 변화/판단 불가로 판정하고, 이미지에서 확인 가능한 근거를 제시하세요. 의상 외 변경을 되돌릴 수 있도록 ChatGPT 이미지 편집용 수정 지시문을 작성해 주세요.
```

검수할 때 지킬 것:
- 판정은 표로: 항목 | 판정 | 근거(어디가 어떻게 다른지).
- 보이지 않는 건 "판단 불가"로 둔다. 추측으로 "유지"라고 하지 않는다.
- 끝에 ChatGPT에 붙여 넣을 수정 지시문을 한 덩어리로 준다. "큰 변화"가 얼굴·머리에 있으면 수정 지시가 아니라 "원본에서 다시 편집"을 권한다.

## 4. 실패를 줄이는 규칙

- 한 번에 **한 벌씩**. 포즈·배경·의상을 동시에 바꾸지 않는다.
- 매번 **원본 마스터를 다시 첨부**하고, 옷 영역만 선택해서 편집한다.
- "완벽히 동일하게"라고 써도 픽셀 수준 일관성은 보장되지 않는다. 기대치를 미리 말해 준다.
- 옷이 머리카락·손과 겹치는 곳은 경계가 조금 바뀌는 게 불가피하다.
- 생성 이미지의 상업적 이용, 초상권은 실제로 쓰는 서비스의 최신 약관을 확인하게 한다. 실존 인물 얼굴로 마스터를 만들지 않는다.

## 5. 15분 첫 테스트

| 순서 | 할 일 | 통과 기준 |
| --- | --- | --- |
| 1 | 마스터 정면 전신 확정 | 얼굴·헤어·체형·화풍 확인 |
| 2 | 정장으로 옷만 변경 | 얼굴·머리·배경 유지 |
| 3 | 캐주얼로 다시 변경 | **원본 마스터에서** 새로 편집 |
| 4 | 두 결과 + 마스터를 Claude로 비교 | 차이점과 재수정 지시 확보 |

ChatGPT로 2~3벌을 먼저 시험하고, 같은 인물의 다양한 포즈까지 필요해지면 그때 전용 학습 모델(LoRA)이나 ComfyUI를 검토한다.

## 6. 의류 브랜드 룩북에 응용할 때

캐릭터 대신 AI 모델에 **실제 판매 상품**을 입히는 경우, 규칙이 하나 더 붙는다.

- 모델 마스터(얼굴·체형·조명)를 먼저 확정하고, 상품마다 원본 마스터에서 새로 편집한다. 그래야 룩북 전체가 같은 모델로 보인다.
- 반대로 **상품이 고정 요소**다. 색상, 핏, 넥라인, 프린트 위치·크기는 실물 사진과 똑같아야 한다. 검수표에 "상품 색상 / 프린트 모양 / 프린트 위치 / 핏" 항목을 추가한다.
- 이미지 AI는 글자와 로고를 다시 그리면서 철자나 모양을 틀리게 만들기 쉽다. 프린트에 문구(예: 성경 구절)가 있으면 글자 하나하나를 실물과 대조하고, 틀리면 실제 프린트 이미지를 합성하는 쪽을 권한다. <프롬프트 2>의 "텍스트나 로고는 추가하지 마세요"는 "상품에 있는 프린트는 첨부한 상품 사진과 똑같이, 그 외 텍스트·로고는 추가하지 마세요"로 바꿔 쓴다.
- 상세 페이지에 쓸 이미지는 실물과 다르면 소비자 오해를 부른다. 색이 틀어진 컷은 쓰지 않는다.
