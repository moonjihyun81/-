# 업리카로 SNS 한 번에 운영하기

업리카(uplika)는 클로드 같은 AI 에이전트에 붙이는 SNS 발행 커넥터(원격 MCP 서버)다.
사용자는 비개발자일 수 있으니 한국어로, 한 번에 한 단계씩 안내한다.
"성공하면" 표시가 있는 곳에서는 그대로 됐는지 사용자에게 확인하고 넘어간다.
`< >`로 감싼 칸은 무엇을 넣을지 사용자에게 먼저 묻는다.
아래에 없는 내용은 지어내지 말고, 모른다고 말한 뒤 공식 매뉴얼(맨 아래 출처)을 안내한다.

## 1. 시작 전 체크

사용자에게 먼저 묻는다.

| 확인할 것 | 조건 | 비고 |
| --- | --- | --- |
| 클로드 계정 | 무료 플랜도 가능 | 무료 플랜은 커스텀 커넥터를 **하나만** 둘 수 있다. 이미 다른 커스텀 커넥터가 있는지 확인 |
| 컴퓨터 브라우저 | 커넥터 추가는 컴퓨터 브라우저의 클로드에서 | 연결 뒤에는 휴대폰 앱에서 말해도 된다 |
| 올릴 SNS 계정 | 어떤 채널을 쓸지 | 인스타그램은 **프로페셔널 계정**(비즈니스·크리에이터), 앱 설정에서 무료 전환 |
| 네이버 블로그 | 업리카 브라우저 확장 설치 | 공식 API가 없어서 확장이 글을 쓴다 |

비용: 베타 기간에는 전부 무료(카드 등록 없음). 연결은 약 5분.

## 2. 클로드에 업리카 연결하기

1. 클로드에서 **Customize**(사용자 정의) → **Connectors**(커넥터)로 간다.
2. **Add**(추가) → **Add custom connector**(사용자 정의 커넥터 추가)를 고른다.
3. 이름 `uplika`, 원격 MCP 서버 주소에 아래 주소를 넣고 **Continue**(계속) → **Add**(추가).

```
https://api.uplika.com/mcp
```

4. 목록의 uplika에서 **Connect**(연결) → 업리카 로그인 화면(구글·깃허브·이메일 로그인 또는 가입).
5. 허용 화면에서 올릴 채널을 연결하고 **허용하고 계속**. 연결된 채널이 하나도 없으면 단추가 잠겨 있으니 그 화면에서 채널 하나를 먼저 연결한다.

> **성공하면** 커넥터 목록의 uplika에 Disconnect(연결 해제)가 보인다. 새 대화에서 "업리카로 연결된 채널 보여 줘"라고 물으면 허용한 채널 목록이 나온다.

API 키를 복사해 붙여넣을 일은 없다.

**클로드 코드**를 쓴다면: 업리카 대시보드 MCP 화면의 **프롬프트 복사**를 눌러 붙여 넣고, 설치가 끝나면 `/reload-plugins`를 입력하면 업리카 도구가 올라온다.

## 3. 첫 글 올려 보기

사용자에게 `<주제>`와 `<채널>`을 물어 채운다.

```
업리카로 <이번 주 새 메뉴 소개> 글을 써서 <인스타그램, 스레드, 네이버 블로그>에 올려 줘.
올리기 전에 채널마다 들어갈 글과 시각을 먼저 보여 주고, 내가 "예"라고 하면 올려.
```

- 업리카 도구를 처음 쓰면 클로드가 허락을 묻는다. **Allow once**(한 번 허용)면 충분하고, 읽기만 하는 도구는 **Always allow**(항상 허용)로 두면 다음부터 안 묻는다.
- 클로드가 올릴 계정·이미지·시각·문구를 먼저 보여 주고 대답을 기다린다. "예"라고 하면 예약된다.
- 예약 글은 업리카 서버가 그 시각에 올리니 컴퓨터를 꺼 둬도 된다(네이버 블로그는 예외, 아래 참고).
- 대시보드 **예약** 화면에서 시각 변경·편집·취소·지금 발행이 가능하다.

**원칙: 사용자 확인 없이는 절대 올리지 않는다.** 글은 사용자 계정으로 바로 나간다.

## 4. 채널별 규칙

업리카가 발행 전에 글자 수와 사진·영상 규칙을 검사하고, 안 맞으면 올리기 전에 막는다.

| 채널 | 글자 수 | 사진·영상 | 연결 방법 |
|---|---|---|---|
| Threads | 500자 | 선택 · 사진 20장 · 영상 1개 | 스레드 로그인 후 허용 |
| Instagram | 2,200자 | 필수 · 사진 10장 · 영상 1개 | 인스타그램 로그인 후 허용 (프로페셔널 계정) |
| YouTube | 5,000자 | 필수 · 사진 불가 · 영상 1개 | 유튜브 로그인 후 허용 |
| Facebook | 63,206자 | 선택 · 사진 10장 · 영상 1개 | 페이스북 로그인 후 페이지 선택 |
| Telegram | 4,096자 | 선택 · 사진 10장 · 영상 10개 | 봇을 하나 만들어 연결 |
| Naver Blog | 30,000자 | 선택 · 사진 40장 · 영상 10개 | 업리카 브라우저 확장 프로그램 |

- 유튜브는 영상이 꼭 있어야 한다. 글만으로는 못 올린다.
- 네이버 블로그 예약 글은 그 시각에 **브라우저가 켜져 있어야** 나간다.
- 연결할 때 요청하는 권한은 모두 허용하라고 안내한다. 하나를 끄면 나중에 DM 같은 기능이 막힌다.

## 5. 댓글 답장과 댓글 → DM

**인박스 답장**: 인스타그램·페이스북 DM, 스레드 멘션, 네이버 블로그 댓글이 업리카 인박스에 모인다.

```
업리카 인박스에서 안 읽은 DM 보여 주고, 하나씩 답장 초안 써 줘. 보내기 전에 하나씩 나한테 보여 줘.
```

- 메시지는 사용자 계정 이름으로 나가니 보내기 전에 하나씩 보여 준다.
- DM은 상대가 마지막으로 메시지를 보낸 뒤 **하루 안에만** 보낼 수 있다.
- 멘션·댓글에 답하면 공개 답글로 올라간다.

**댓글 → DM**: 내 글에 댓글 단 사람에게 DM으로 링크·파일을 보내는 자동화. DM 권한으로 연결한 인스타그램·페이스북 계정에서 된다. `<키워드>`와 `<안내 자료 링크>`를 사용자에게 묻는다.

```
업리카로 최근 릴스에 <자료>라고 댓글 단 사람에게 DM으로 <안내 자료 링크>를 보내는 자동화를 초안으로 만들어 줘.
```

- 자동화는 **꺼진 초안**으로 만들어진다. 사용자가 읽고 고칠 곳을 말한 뒤 켜 달라고 하면 켠다.
- 켜 둔 자동화는 업리카 서버에서 돌아서 클로드를 닫아도 계속 일한다.
- 스레드에는 DM이 없다. 대신 **댓글 → 대댓글**로 공개 답글을 단다.

> **안 될 때** `reconsent_required`가 나오면 인스타그램 계정이 메시지 권한 없이 연결된 것이다. 업리카 **연결** 화면에서 그 계정의 **다시 연결**을 누르고 권한을 전부 허용한다. 페이스북을 거쳐 연결했다면 Meta 화면에서 **설정 수정**을 눌러 새 권한을 켠다.

## 6. 키워드 조사와 블로그 검색 노출 진단

"업리카로"를 같이 말하면 웹 검색 대신 업리카 도구로 찾는다.

| 도구 | 하는 일 |
|---|---|
| 유튜브 검색 | 검색어로 영상을 찾고 조회수 ÷ 구독자 수를 보여 준다. 1 이상이면 채널 크기보다 주제가 사람을 더 끈 영상 |
| 네이버 키워드 조사 | 키워드별 한 달 검색량과 이미 쌓인 글 수, 같이 쓰면 좋은 키워드 묶음 |
| 구글 키워드 | 나라를 고르고 키워드 최대 10개 → 월 검색량, 광고 경쟁, 연관 키워드 |

네이버 블로그용:
- **AI 브리핑 확인**: 키워드를 넣으면 네이버 AI 브리핑이 어느 글을 출처로 골랐는지, 블로그 글이 검색에서 몇 번째인지 보여 준다.
- **블로그 진단**: 내 블로그 최근 글을 하나씩 네이버에서 검색해 AI 브리핑 인용 여부와 순위를 확인한다. 몇 분 걸린다.

```
업리카로 <홈카페 레시피> 네이버 키워드 조사해 줘. 검색량은 많은데 글이 적은 키워드 묶음을 골라서 블로그 글 제목 3개 제안해 줘.
```

```
업리카로 지난 한 달 <클로드 자동화> 유튜브 영상 중에 채널 크기보다 잘된 걸 찾아서, 내 영상 제목을 몇 개 제안해 줘.
```

- 유튜브 검색은 하루 200번까지. 같은 검색을 24시간 안에 다시 하면 저장된 결과를 쓰고 횟수에 세지 않는다.
- AI 브리핑 확인과 블로그 진단은 네이버 블로그 연결(확장 설치)이 먼저 돼 있어야 한다.

## 7. 무료 범위와 주의할 점

**무료 범위**(2026년 11월 10일 공식 사이트 기준)
- 베타 기간 전부 무료, 카드 등록 없음, 워크스페이스 수 제한 없음.
- 정식 출시 뒤 예정 가격: 무료(월 20개 발행), Pro 월 10달러(무제한), Enterprise 월 20달러. 공식 사이트도 확정 가격이 아니라고 밝힌다.
- 클로드 무료 플랜은 커스텀 커넥터 하나까지.

**주의할 점**
- **브랜드가 여럿이면 워크스페이스를 나눈다.** 워크스페이스 하나에 플랫폼마다 계정 하나만 연결된다. 클로드에게 말할 때 워크스페이스 이름을 같이 말한다.
- **"예" 전에 꼭 읽어 본다.** 글은 사용자 계정으로 바로 나간다.
- **연결 해제**: 클로드 커넥터에서 Disconnect, 또는 업리카 대시보드 MCP 화면의 승인된 클라이언트에서 해제.
- **토큰 만료**: 업리카 **연결** 화면에서 **다시 연결** → 같은 계정으로 로그인. 기존 연결과 글은 그대로 남는다.
